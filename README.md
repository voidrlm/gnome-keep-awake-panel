# Keep Awake (Panel)

Top-bar sun icon that keeps the screen on (no dim, lock or suspend). Click to toggle.

GNOME Shell extension (45–50).

## Install

```sh
git clone https://github.com/voidrlm/gnome-keep-awake-panel.git ~/.local/share/gnome-shell/extensions/keep-awake-panel@arjun
gnome-extensions enable keep-awake-panel@arjun
```

Log out and back in (Wayland) for GNOME to discover it.
